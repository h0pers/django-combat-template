# Getting help

1. **Read the docs.** The [README](README.md) covers setup, options, architecture and deployment. The generated project has its own README with day-to-day commands.
2. **Search existing issues.** Someone may already have asked: [open and closed issues](https://github.com/h0pers/django-combat-template/issues?q=is%3Aissue).
3. **Ask.** Open a [new issue](https://github.com/h0pers/django-combat-template/issues/new/choose) using the **Question** form.

Found a bug or want a feature? Use the **Bug report** or **Feature request** form instead.

Found a security problem? Do not open an issue. Follow [SECURITY.md](SECURITY.md).
